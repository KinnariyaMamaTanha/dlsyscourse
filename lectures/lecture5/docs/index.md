# Needle Documentation

Needle is a lightweight deep learning framework designed for educational purposes. It provides a PyTorch-like interface and implements automatic differentiation (autograd) from scratch.

## Overview

Needle is built with simplicity and educational value in mind. It helps students understand:
- How automatic differentiation works under the hood
- Core concepts of deep learning frameworks
- Implementation of basic neural network operations

## Key Features

- Automatic differentiation engine
- NumPy-based backend for efficient computation
- Tensor operations similar to PyTorch/NumPy
- Clean, readable implementation for learning
